# 阿斯塔特音效来源

## 战吼

`warcry-en.wav` 取自社区音板的星际战士语音条目，裁去句前的杂音，调整音高、均衡和电平后转为单声道 WAV。[Blerp · For the emperor](https://blerp.com/soundbites/5d77413a73232d0005ce207b)

## 男声动作音效

VoiceBosch（SoundBiter）录制的下列素材用于发力、受伤、喘息、对白短音及相关混音。改编处理包括裁切、降调、均衡、归一化及部分重组。原录音及其改编音频适用 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。

- `exert1–4`、`frustration`、`speech1`、`speech3–4` 取自 18、21、32、36、40 号发力录音。[EFFORT SOUNDS (Male)](https://voicebosch.itch.io/exertion-sounds-male-audio-pack)
- `pain1–3`、`fall`、`speech2` 取自 03、11、17、22 号受伤录音。[PAIN SOUNDS (Male)](https://voicebosch.itch.io/taking-damage-sounds-male-grunts-audio-pack)
- `pant`、`gearshake`、`swallow`、`nausea`、`nausea-blood` 使用 02、04 号呼吸录音。`gearshake` 加入模组原有的甩水和装备摩擦声。[BREATHING SOUNDS](https://voicebosch.itch.io/breathing-sounds-audio-pack)

## 哈欠、伸展和干呕

- `yawn1–2`、`stretch` 取自 Benni Knop 的录音，裁切并重新均衡。原录音适用 CC0。[Male Yawn Yawning Stretch Stretching Lifting Grunt](https://freesound.org/people/benniknop/sounds/317845/)
- `retch1–2` 取自 Breviceps 的录音，裁切并降调。原录音适用 CC0。[Gagging / Vomit / Throwing up](https://freesound.org/people/Breviceps/sounds/446001/)
