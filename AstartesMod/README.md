# 阿斯塔特角色模组

适用《Casualties: Unknown》Steam 正式版，开发与验证基准为 Build 26590676，使用 BepInEx 5。

## 使用

从 Steam 启动游戏，进入新局选角，选择第四位「[AST-01] 阿斯塔特」。新局穿戴六件 Mk X 动力甲，主手持爆弹枪，副手持链锯剑，动力背包的弹舱内有两个备用弹匣。动力甲可在原版穿戴栏逐件卸下和重新穿戴。读档恢复装备、槽位、耐久和装弹状态。

## 本体数值

| 裸装数值 | 默认 |
|---|---:|
| 力量 / 韧性 / 智力 | 34 / 32 / 28 |
| 跑速倍率 | 1.55 |
| 起跳速度倍率 | 1.35 |
| 体力上限 | 原版的 10 倍，体力条仍显示百分比 |
| 体力恢复倍率 | 每单位时间恢复量为原版的 3.50 倍 |
| 血容量 | 9 L，失血和输血按实际体积换算 |
| 凝血 | 基础速度为原版的 3 倍，下限 2.5 点/秒，再按原版愈合设置结算 |
| 自然愈合 | 无异物的活体肢体每秒至少恢复 1.8 点皮肤、1.2 点肌肉，受原版愈合设置和饥饿影响 |
| 骨折愈合时间 | 生物肢体为原版的 1/10，难度与夹板仍参与结算，读档继承骨折进度 |
| 体温 / 情绪 | 36.5–37.5 °C / 至少 10 |
| 毒素 / 感染 / 患病 | 免疫原版毒液、感染与败血症，食物等来源的患病增量为原版的 10% |
| 水流 | 推力、失足和冲倒累积为原版的 5% |
| 裸装肢体防护系数 | +1.25 |
| 第二心脏 | 每局一次，在脑健康归零时恢复循环和意识，血量回到至少 80% |
| 贝利撒留炉 | 每局一次，在危及生命的失血或头部创伤时排出破片、止血、缓解疼痛和休克，并愈合仍有活性的肢体骨折及脱臼 |

可编辑 `BepInEx/config/casualtiesunknown.astartes-mod.cfg` 的 `[Astartes]` 来调节初始技能、跑速、起跳、体力恢复、凝血倍率和裸装防护。重启游戏后生效。继续游戏时，原有技能、伤口、体力比例和血量比例随存档恢复，强化体质使用当前版本的数值。

贝利撒留炉在剩余血量低于 65% 且仍有持续净失血，或脑健康不高于 15/100 且头部存在骨折、破片或严重肌肉损伤时点燃。启动后仍按当前的血量和脑健康继续结算。第二心脏与炉子的使用状态分别保存，换层和读档会恢复相应状态。升级前的旧档中两个器官均可使用。

## 开局装备

| 部件 | 覆盖部位 | 防护系数 |
|---|---|---:|
| 动力头盔 | 头 | +4.50 |
| 胸腹甲 | 胸、腹 | +5.00 |
| 肩甲 | 双上臂 | +3.60 |
| 臂甲与手甲 | 双前臂、双手 | +3.00 |
| 腿甲与战靴 | 双大腿、双小腿、双脚 | +3.50 |
| 动力背包 | 胸 | +0.65 |

防护系数与原版防护相加，最终减伤按游戏的原有公式计算。穿戴腿甲时起跳额外提高 12%，阿斯塔特穿戴有耐久的动力背包时跑速额外提高 15%。动力背包穿戴后自动点亮半径 36 游戏单位的泛光灯，卸下或损坏时熄灭。动力头盔提供听力防护。

六件 Mk X 动力甲、链锯剑和爆弹枪的耐久相对 2.3.1 版提高到三倍。穿戴受击、武器使用、装备受到冲击和链锯剑用作切割工具时，耐久磨损按原来的三分之一结算。旧档继承耐久百分比。

链锯剑使用原版近战系统。基础生物伤害 120、结构伤害 96、攻击距离 7.2。命中怪物后，基础冷却约为 0.185 秒，相当于 2.4.1 版的五分之一。空挥和砍障碍物的基础间隔为 0.40 秒。每次命中消耗约 0.0167 个百分点耐久。力量、手臂状态和难度仍参与实际伤害计算。

爆弹枪使用原版枪械操作，支持全自动射击、保险、拉栓和换弹。单发生物伤害 600、结构伤害 400，循环间隔 0.09 秒。开局共 180 发，其中 60 发装在枪内，120 发分装在背包的两个备用弹匣里。

## 构建与安装

```powershell
dotnet build AstartesMod/AstartesMod.csproj -c Release
```

可通过 `-p:GameDir="游戏安装路径"` 指定正式版目录。将 `AstartesMod/bin/Release/` 中的 `AstartesMod.dll`、`modinfo.json` 与 `Sprites/` 复制到 `BepInEx/plugins/AstartesMod/`。

## 角色和存档

角色 ID 为 `astartes`，以正式版实验体的身体预制体为骨架。落地、换层和结局的角色画面使用独立贴图。死亡界面按原版条件显示阿斯塔特的普通死亡、失血或水中死亡插图。中英台词各 1,512 句，按正式版实验体的 88 个玩家台词条目逐项对齐，每种语言另有一条专属着陆台词。原版对白系统按情境抽选台词，词表位于 `Dialogue/`，构建时随 DLL 嵌入。包扎、注射、取异物、复位等操作使用阿斯塔特的人手和黑色袖口，左右手和工具动作由原版交互逻辑控制。伤势界面的部位图沿用原版。

发声键默认是 **B**，各语言固定播放同一段英文战吼「For the Emperor!」。对白短音、喘息、发力、疼痛、哈欠、惊叫和干呕采用统一的低沉男声处理，穿戴头盔时叠加轻度通讯滤波。音效构建时随 DLL 嵌入。[音效来源与署名](Audio/SOURCES.md)

存档顶层字段 `casualtiesunknown.astartes-mod` 保留角色身份。读档与 QoL Unknown 换层从实际恢复的存档读取该字段。旧版换层后身份已丢失的存档，可用穿戴中的 Mk X 动力甲识别。开局武器和初始技能随新局发放。

角色、动力甲、武器和过场贴图使用内置 ImageGen 制作。[美术参考与提示词](Art/prompt.md)
